# GrabLine 1.32.9

Switching between Downloads, Dashboard, and Settings is smoother. On Linux,
checking VPN status could pause the entire app for several seconds because
interface link-speed detection blocked the UI. GrabLine now reads just the
interface state needed for the VPN indicator. Settings opens without waiting
for that check, and dashboard statistics update in the background.

Settings lays out each section when opened. The Downloads table also avoids
redrawing while another page is visible and catches up when you return. The
Dashboard reuses unchanged table rows, and its refresh interval takes effect
immediately after saving Settings.

In an offscreen Linux profile using a temporary database, first opening
Settings fell from 4.20 s to 0.55 s on the same machine. Actual timing depends
on the system. The regression suite covers slow interface checks, navigation,
background refresh recovery, and table updates.
