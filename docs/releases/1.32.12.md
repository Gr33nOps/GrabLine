# GrabLine 1.32.12

This patch rebuilds the desktop installers with the tested PySide 6.11 series. The newer 6.12 series caused the Linux GUI test process to abort during Qt shutdown after its tests had passed. Pinning the dependency keeps the packaged runtime and CI validation on the same stable version.

The queue display and browser takeover fixes introduced in 1.32.11 remain included. GrabLine Connect packages are versioned 1.32.12 to match the desktop release; their behavior is unchanged from 1.32.11.
