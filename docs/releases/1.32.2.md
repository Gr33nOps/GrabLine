# GrabLine 1.32.2

Downloads from an LMS or other website can have extensionless or generic names
such as `pptx`, `download`, or `download.php`. GrabLine now uses the response
metadata consistently to recover useful file names across file types.

- Prefer encoded `filename*` headers over basic fallback filenames, preserving
  international characters and the full server-provided extension.
- Restore missing extensions for Word, Excel, PowerPoint, PDF, OpenDocument,
  e-books, archives, images, audio, video, installers, and other recognized MIME
  types. Existing extensions, including custom formats, are preserved.
- Read explicit `filename`/`file` query parameters on generic LMS endpoints and
  recover filenames from redirects. A PHP download endpoint returning a PDF no
  longer causes an automatically named download to be saved as a PHP file.
- Reject HTML login/error responses when a known non-HTML file was requested,
  including when a login expires between the initial probe and the transfer.
  Actual HTML downloads remain supported.

GrabLine's direct downloader transfers bytes regardless of the format: this is
not a file-type whitelist. Unknown/custom extensions and generic binary responses
remain supported. When neither a name nor a useful MIME type is supplied, GrabLine
keeps the available name instead of inventing a potentially incorrect extension.
These changes improve filename and response handling; they cannot make expired
links, unavailable servers, authentication failures, or network errors impossible.

## Verify

1. Update GrabLine and sign into the website/LMS in your browser.
2. Download a presentation, PDF, Word/Excel document, archive, or media file.
   Confirm the saved name has the expected extension and opens in its application.
3. Test a filename-bearing LMS URL or a redirect: the final name should reflect
   the file, rather than the download endpoint.
4. Where a checksum is provided by the publisher, compare it with the saved file.
5. If the session expires, sign in again and retry with the browser extension;
   an HTML login response must not appear as a completed document or archive.

Regression coverage includes byte-for-byte downloads across file categories,
Unicode headers, filename query parameters, redirects, generic/custom formats,
cached metadata, session expiry, and legitimate HTML downloads.
