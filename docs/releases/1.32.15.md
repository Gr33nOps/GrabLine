# GrabLine 1.32.15

This release combines the Windows audit fixes with improvements to download
isolation, media recovery and the download website. Update both the desktop app
and GrabLine Connect to 1.32.15 to receive the browser handoff and overlay fixes.

## Download reliability

- Downloads with the same filename reserve distinct partial-file names, including
  names supplied later by a server. Cloud downloads preserve existing files.
- A changed server file that returns an out-of-range response can be retried with
  a fresh probe. A full disk stops automatic retries.
- HLS processing drains FFmpeg errors continuously, honours cancellation during
  local merging, stops outstanding segment work after a fatal segment error and
  preserves useful cached segments after a dropped connection.
- Cancelling or removing paused media jobs removes their leftover scratch data.
  Cleanup preserves differently named downloads and backup files.

## Windows, settings and browser integration

- Windows native crash logging avoids the all-thread traceback walk that
  reproduced a native crash during accessibility inspection. It retains the
  faulting thread's trace.
- Settings import/reset refresh visible controls, RSS/watch-folder intervals
  update immediately, and the Windows FFmpeg installer uses a verified current pin.
- Cloud account/URL handling, encrypted archive extraction, completion hooks and
  browser handoff deduplication/recovery include the Windows audit corrections.
- Browser media discovery and hover-button positioning handle more scrolling,
  overlap and navigation cases.
- Malformed VirusTotal and Safe Browsing responses remain advisory failures
  instead of escaping as exceptions.

## Website

- Phones and tablets no longer receive a misleading desktop-specific download.
- Mobile navigation has an opaque background, nested missing-page URLs retain
  their assets, and the sitemap date follows the website's Git history.
- Privacy information describes automatic tool downloads and optional connectivity
  checks more accurately. An unused font asset has been removed.

## Verification scope

The combined revision is checked with the Windows test suite, extension tests,
lint, formatting, dependency/type checks and a rebuilt packaged transfer smoke
test. Native release artifacts are built on Windows, macOS and Linux runners.

Local tests do not certify every public media site or private cloud provider.
Persistent reboot/login, supported physical battery/power states, router mappings,
visible Windows toast delivery, human audibility and authenticated reputation APIs
retain their previously documented environment/account limitations. The installer
handoff check uses a benign fixture; it does not certify every previous-version
upgrade. Builds remain unsigned.
