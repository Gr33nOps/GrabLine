# GrabLine 1.32.11

Queue Manager now stops counting a running download as soon as it is removed from the download list. Previously the manager kept counting that job until its worker stopped, so the queue could show an active download that the list no longer displayed. Pending jobs are labeled "Waiting to start" to distinguish their scheduler state from membership in a named queue, and the default card is labeled "Downloads outside named queues."

GrabLine Connect now restores Chromium's download UI suppression after a browser-owned download finishes. One download that stayed in the browser previously kept its UI visible for later GrabLine takeovers. Completion and removal events, plus a state check for fast downloads, clear that temporary exception.

Automatic takeover still keeps the original browser download paused until GrabLine completes, so the browser can resume it if the desktop transfer fails. Firefox does not offer Chromium's download UI suppression API; use **Download with GrabLine** from the browser context menu for a handoff that never starts a browser download.
