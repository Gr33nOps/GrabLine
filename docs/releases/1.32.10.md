# GrabLine 1.32.10

Google Drive file links, including `drive.usercontent.google.com/download` URLs, now use the direct downloader. GrabLine adds the confirmation parameter needed for large public files instead of sending these links to yt-dlp, which could fail with an HTTP 400 metadata error. Share links, pasted links, and browser handoffs use the same path.

Direct downloads from non-range servers now use the size of the completed transfer. A dynamic endpoint could return a different body size from its earlier probe and previously fail with repeated "server closed the connection early" errors even after transferring the whole response.

GrabLine Connect no longer records transient YouTube playback chunks as media finds. This avoids repeated tab lookups and extension-storage writes during playback while keeping manual YouTube grabs and normal media detection available.
