# GrabLine 1.32.4

YouTube downloads now enable JavaScript challenge solving before the first
transfer even when no browser profile is detected. Previously, download-ready
prefetch enabled it, but a fresh download could start without it. That mismatch
could return limited formats or fail before retrying with the runtime.

Raised the minimum yt-dlp version to 2026.08.19 after the older development
version failed a TikTok sample that succeeded with the current stable extractor.

Browser-session handling, non-YouTube fast paths, explicit runtime paths,
fragment concurrency, merging, and resume behavior remain intact. Added coverage
for watch, short-link, Shorts, live, and embedded YouTube URLs without a browser,
and a real DASH download that verifies both tracks and complete duration.

## Verification performed

- Live YouTube metadata/quality analysis passed for regular, 4K/HDR, 8K, 60fps,
  Shorts, age-gated sample, playlist, and live sample URLs.
- A Short downloaded completely: 19.021 seconds with video and audio.
- MP3 extraction of that video completed: 19.032 seconds, MP3 audio plus cover art.
- A 60fps sample downloaded completely: 634.624 seconds with video and audio.
- Dailymotion and SoundCloud metadata checks passed. TikTok passed with the
  updated extractor; the Vimeo sample returned HTTP 404.
- Automated media tests cover HLS, DASH, MP3/M4A/FLAC conversion, metadata,
  cookie-store fallback, resume, cancellation, and incomplete-fragment handling.

Metadata success does not prove full downloads at every resolution, and the
sample tests do not guarantee every YouTube video. Removed/private content,
DRM, region/account restrictions, site changes, and network conditions still
apply. Live streams have no fixed full duration until they end.

## Verify on your machine

Update GrabLine, reload the page, and use the hover button on a public video or
Short. Try video and audio-only output; confirm playback, audio, and duration.
On a machine without a browser profile, GrabLine should now select or provision
its JavaScript runtime before the first YouTube transfer.
